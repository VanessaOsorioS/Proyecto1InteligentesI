TacticalGrid

TacticalGrid es un proyecto de juego desarrollado en un contexto académico. Este repositorio reúne el código fuente y la documentación necesaria para comprenderlo, ejecutarlo y utilizarlo.

Instalación y ejecución

1. Descarga o clona este repositorio.
2. Instala las dependencias indicadas en los requisitos.
3. Ejecuta el proyecto con el siguiente comando:

* python main.py
